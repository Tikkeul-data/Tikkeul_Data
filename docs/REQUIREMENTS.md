# 요구사항

우선순위: P0(필수) > P1 > P2. 제외 항목은 만들지 않는다.

## 1. 기능 요구사항

| ID | 우선순위 | 요구사항 | 완료 기준 (초안) |
|---|---|---|---|
| F-01 | P0 | 후면 카메라 영상에서 YOLO로 객체를 탐지한다 | 테스트 영상에서 대상 객체가 탐지되어 화면에 표시된다 |
| F-02 | P0 | ROI(관심 영역) 안에 객체가 들어오면 안전 경고를 낸다 | ROI 안/밖 입력에서 경고 발생 여부가 기대와 일치한다 |
| F-03 | P0 | GPS·시간·보호구역을 결합해 경고를 상황에 맞게 조정한다 | 같은 탐지라도 보호구역/시간대 조건에 따라 경고 수준이 달라진다 (조정 규칙 TBD) |
| F-04 | P0 | 교통 정체·공사·통제 정보를 보여준다 | 현재 위치 주변 정보가 표시된다 (데이터 출처 TBD) |
| F-05 | P0 | 어린이보호구역 및 주변 위험지역을 안내한다 | 보호구역 진입/근접 시 안내가 표시된다 |
| F-06 | P0 | 한국어·영어·중국어를 지원한다 | 3개 언어 전환 시 모든 사용자 문구가 번역되어 표시된다 |
| F-07 | P0 | 네트워크 장애를 표시하고 데이터 갱신 시각을 보여준다 | 네트워크 차단 시 장애 표시와 마지막 갱신 시각이 보인다 |
| F-08 | P1 | AI 시야 상태를 평가한다 | 평가 기준·출력 형식 TBD |
| F-09 | P1 | 동의한 사용자의 경고 관측 이벤트를 지도에 표시한다 | 동의하지 않은 사용자의 데이터는 수집되지 않는다 |
| F-10 | P2 | 사이렌·경적 오디오를 분류한다 | 분류 대상·정확도 기준 TBD |
| F-11 | P2 | 청각 약자를 위해 화면·진동으로 안내한다 | 오디오 분류 결과가 화면·진동으로 전달된다 |
| F-12 | P1 | 로그인/비로그인을 구분하고, 비로그인 상태에서 로그인 전용 기능을 누르면 로그인 화면으로 이동한다 | 로그인 없이 즐겨찾기 등 로그인 전용 기능을 누르면 로그인 화면으로 이동한다 |
| F-13 | P1 | 로그인한 사용자는 즐겨찾기(집/회사/커스텀)를 등록하고 탭해서 바로 길안내를 시작할 수 있다 | 즐겨찾기 탭 시 별도 검색 없이 길안내가 시작된다 |
| F-14 | P1 | 로그인한 사용자의 최근 목적지를 서버에 동기화한다(기기 간 공유, 기존 localStorage 방식 대체) | 다른 기기로 로그인해도 같은 최근 목적지 목록이 보인다 |
| F-15 | P1 | 포그라운드 상태에서 자주 다니는 경로와 현재 이동이 일치하면 길안내 시작을 제안한다(상시 백그라운드 위치 추적 없음) | 반복된 출발·목적지 패턴에서 제안 카드가 뜨고, 앱이 백그라운드일 때는 위치를 추적하지 않는다 |

설계 상세는 [AUTH_DESIGN](AUTH_DESIGN.md) 참고.

경고 방식: 화면 경고, TTS, 진동.

### 제외

- 포트홀 탐지
- 졸음 감지
- 전·후면 동시 카메라 촬영

## 2. 비기능 요구사항

| ID | 구분 | 요구사항 |
|---|---|---|
| N-01 | 개인정보 | 카메라 원본 영상을 기본적으로 서버로 전송하지 않는다 |
| N-02 | 개인정보 | 위치정보 수집을 최소화한다 |
| N-03 | 보안 | 키·토큰을 코드에 넣지 않고 `.env`로 관리한다 |
| N-04 | 보안 | 로그에 민감정보를 남기지 않는다 |
| N-05 | 표현 | AI 탐지 결과를 사고·충돌 확정으로 표현하지 않는다 |
| N-06 | 성능 | 경고가 안전에 쓸모 있을 만큼 지연이 짧아야 한다 (목표 수치 TBD) |
| N-07 | 안정성 | 네트워크 장애 시에도 앱이 중단되지 않는다 |
| N-08 | 일정 | 개발 기간 7일. P0 우선 완성 후 P1, P2 |
| N-09 | 품질 | 타입을 명확히 하고(TS 타입, Python 타입 힌트) 요청·응답을 검증한다 |
